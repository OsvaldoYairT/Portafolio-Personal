Systems and Databases

Who it is for: companies that need an internal system to centralize information and replace manual processes.

I build business systems with .NET connected to databases, following a layered architecture so the code stays maintainable and business rules stay separate from the interface.

What it includes

  • Modules for creating, querying, updating and deleting records
  • Data access with ADO.NET, Entity Framework and AJAX
  • SQL Server, MySQL and Oracle
  • Integration with SOAP services and REST APIs

Automation and Integration

When a process repeats every day, it can be programmed. I build scripts, services and integrations to cut down manual work and let information flow without manual steps in between.

Frequently Asked Questions

Quick answers before you request a quote

What kind of projects can you do?

I build websites and web applications, database-backed systems and process automation. Those are the services I take on in most projects. As complementary support I also offer visual content, technical support and social media.

How do you make sure the project works?

I test everything before delivering it, so that it works completely, is compatible with different browsers and meets the agreed specifications. I also document the problem, the solution and the technologies used in each project, so you know exactly what was built and why.

Which technologies do you work with?

For web development: HTML5, CSS3, JavaScript, jQuery and Bootstrap. For systems and databases: SQL Server, MySQL and Oracle, with ADO.NET, Entity Framework and AJAX. For automation and integrations: Python and C#, consuming REST and SOAP APIs.

What happens after delivery?

I offer technical support and maintenance to fix errors in frontend and backend, maintain databases and handle the support queries that come after delivery. If your project needs it, I can also manage the visual content or the social media profiles.

How much does a project cost?

It depends on the scope, the content, the features and the integrations you need. We settle that in the first conversation: you tell me what you want to achieve and I prepare a proposal with what it includes and which technologies will be used.
