Services I Offer

What I do, who it is for and how to request it

Main offer

I build websites and web applications, database-backed systems and automations. These are the services most projects start with.

Web Development

Who it is for: businesses that need their own website, either from scratch or to replace the one they currently have.

The message comes first. A good design communicates a clear idea instead of just decorating. I design the interface and then turn it into a fast, mobile-friendly website that actually works.

What it includes

  • Interface and user experience design
  • Responsive site for mobile, tablet and desktop
  • Built with HTML5, CSS3, JavaScript, jQuery and Bootstrap
  • Contact forms, galleries and content sections
Request a quote

Systems and Databases

Who it is for: companies that need an internal system to centralize information and replace manual processes.

I build business systems with .NET connected to databases, following a layered architecture so the code stays maintainable and business rules stay separate from the interface.

What it includes

  • Modules for creating, querying, updating and deleting records
  • Data access with ADO.NET, Entity Framework and AJAX
  • SQL Server, MySQL and Oracle
  • Integration with SOAP services and REST APIs
Request a quote

Automation and Integration

Who it is for: companies with repetitive tasks or information that is currently moved by hand between several systems.

When a process repeats every day, it can be programmed. I build scripts, services and integrations to cut down manual work and let information flow without manual steps in between.

What it includes

  • Scripts and tools in Python and C#
  • Windows services for background processes
  • Integration and consumption of REST and SOAP APIs
  • Automation of billing processes and reports
