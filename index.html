Respuestas rápidas antes de solicitar una cotización

¿Qué tipo de proyectos puedes hacer?

Desarrollo sitios y aplicaciones web, sistemas con base de datos y automatizaciones de procesos. Esos son los servicios que pido en la mayoría de los proyectos. Como apoyo complementario también ofrezco contenido visual, soporte técnico y redes sociales.

¿Cómo te aseguras de que el proyecto funcione?

Pruebo todo antes de entregarlo, para que funcione por completo, sea compatible con distintos navegadores y cumpla con las especificaciones acordadas. Además, en cada proyecto documento el problema, la solución y las tecnologías que se usaron, para que sepas exactamente qué se construyó y por qué.

¿Con qué tecnologías trabajas?

Para desarrollo web: HTML5, CSS3, JavaScript, jQuery y Bootstrap. Para sistemas y bases de datos: SQL Server, MySQL y Oracle, con ADO.NET, Entity Framework y AJAX. Para automatización e integraciones: Python y C#, consumiendo APIs REST y SOAP.

¿Qué pasa después de la entrega?

Ofrezco soporte técnico y mantenimiento para corregir errores en frontend y backend, dar mantenimiento a las bases de datos y atender las consultas de soporte posteriores a la entrega. Si tu proyecto lo requiere, también puedo administrar el contenido visual o los perfiles de redes sociales.

¿Cuánto cuesta un proyecto?

Depende del alcance, el contenido, las funcionalidades y las integraciones que se necesiten. Lo definimos en la conversación inicial: me cuentas qué quieres lograr y te preparo una propuesta con lo que incluye y con qué tecnologías se va a trabajar.
