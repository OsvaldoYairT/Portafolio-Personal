Oferta principal

Desarrollo sitios y aplicaciones web, sistemas con base de datos y automatizaciones. Son los servicios que pido en la mayoría de los proyectos.

Desarrollo web

Para quién es: negocios que necesitan un sitio web propio, ya sea desde cero o para renovar el que tienen.

El mensaje es lo primero. Un diseño bien hecho transmite una idea clara en lugar de solo decorar. Desarrollo la interfaz y después la convierto en un sitio funcional, rápido y adaptado a móvil.

Qué incluye

  • Diseño de la interfaz y la experiencia de usuario
  • Sitio responsivo para móvil, tablet y escritorio
  • Desarrollo con HTML5, CSS3, JavaScript, jQuery y Bootstrap
  • Formularios de contacto, galerías y secciones de contenido

Sistemas y bases de datos

Para quién es: empresas que necesitan un sistema interno para centralizar información y reemplazar procesos manuales.

Construyo sistemas empresariales con .NET conectados a bases de datos, siguiendo arquitectura en capas para que el código sea mantenible y las reglas de negocio queden separadas de la interfaz.

Qué incluye

  • Módulos de altas, consultas, modificaciones y bajas
  • Acceso a datos con ADO.NET, Entity Framework y AJAX
  • SQL Server, MySQL y Oracle
  • Integración con servicios SOAP y APIs REST

Automatización e integración

Para quién es: empresas con tareas repetitivas o información que hoy se mueve a mano entre varios sistemas.

Cuando un proceso se repite todos los días, se puede programar. Desarrollo scripts, servicios e integraciones para reducir las tareas manuales y que la información fluya sin pasos intermedios.

Qué incluye

  • Scripts y herramientas en Python y C#
  • Servicios Windows para procesos en segundo plano
